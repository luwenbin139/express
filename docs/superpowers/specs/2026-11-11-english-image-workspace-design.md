# 英语图片工作台设计

为教材插画制作新增独立的 `/english` 页面。原有页面与原有生成接口保持原来的行为。

人物流程支持上传教材截图、调用视觉模型提取特征、人工审核编辑描述并生成三视图，另支持上传角色图并直接修改。场景流程按原图、角色参考图及映射、可选背景参考图的顺序提交；使用飞书文档的默认提示词，允许编辑特别要求，默认 16:9。道具流程以场景原图和可选道具参考图生成修改结果。结果支持预览和下载。

新接口独立限制为最多 16 张图、每张 20 MB、总计 40 MB；保留原有接口的限制和行为。角色识别使用现有服务地址和密钥，默认模型为 `gpt-5.6`，可通过 `ENGLISH_VISION_MODEL` 覆盖；识别结果仅供人工审核。独立图片接口复用已验证的图片服务流转换。场景映射缺失时阻止生成；图片顺序和提示词编号一致。生成中的错误、取消和服务不支持的错误需要显示给用户。

衣着以场景原图为准，角色图用于身份和外貌；特别要求优先。默认清除教材文字和对话框，文字类道具保留模糊的颜色与轮廓，思考气泡保留。旧页面无需更改，独立路径由服务端提供 SPA 入口。
